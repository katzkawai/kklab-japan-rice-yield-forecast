# 日本のコメ（主食用米）収穫量の推移と将来予測

農林水産省「作物統計調査」（2020〜2026年産）に基づく主食用米の収穫量・需要・民間在庫・相対取引価格の推移と、2040年に向けた中長期試算（農林水産省の需要トレンド試算、全米販「米穀流通2040ビジョン」）を1ページにまとめた静的サイトです。

- 公開ページ: https://katzkawai.org/kklab-japan-rice-yield-forecast/ （GitHub Pages。https://katzkawai.github.io/kklab-japan-rice-yield-forecast/ からもリダイレクトされます）
- 構成: `index.html` のみ（Chart.js 4.4.1 を CDN から読み込み）。ビルド不要で、ファイルをブラウザで開けば表示できます。

## 主なデータ

| 項目 | 出典 |
|---|---|
| 作付面積・10a当たり収量・収穫量（2020〜2026年産、両ふるい目幅基準）・作況単収指数 | 農林水産省「令和8年産水稲の作付面積及び9月25日現在の予想収穫量」（2026年10月13日公表、累年データ） |
| 需要実績・需要見通し・生産量見通し・民間在庫 | 農林水産省「米穀の需給及び価格の安定に関する基本指針」（2026年7月）、食糧部会 参考資料「米の需給見通しについて」（2026年7月） |
| 相対取引価格 | 同上（2025年産は2026年6月までの速報値） |
| 2040年 需要トレンド試算（493万t） | 農林水産省 基本法検証部会 資料3（2022年12月） |
| 2040年 需要375万t・生産可能量363万t・基幹的従事者30万人、野心的シナリオ | 全米販・日本総合研究所「米穀流通2040ビジョン」（2024年6月） |

2026年産の数値は概数値で、長雨・災害の影響は次回公表（10月25日現在、2026年11月中旬予定）で反映されます。
